# release-files

Build outputs for each version of 4x4 Evolution 2026 Edition, one folder per version. The source code is on `main`.

Each version folder contains:

- **The all-in-one installer:** `4x4Evolution2026-Setup.exe` and its `-N.bin` slices. Download them all into one folder, then run the exe.
- **The evo2026 kit** (`evo2026-kit-*.zip`), for patching an existing Build 57 install.
- **HD texture packs** (`textures-*.zip`).
- **`SHA256SUMS.txt`** and **`RELEASE-NOTES.md`**.

The installer contains game files from a personal copy of the game. Keep this repository private.
